Gmsh e malhas

1 Gmsh e malhas para o BEM

A geometria com Gmsh + BEM_gmsh (.geo, orientação, format2d, shapefun, geometric_props, elementos descontínuos) está no capítulo Indo para 2D.

Este capítulo só fixa o que ainda não entra lá: o papel dos grupos físicos como portadores de CDC e o caminho até o solver. O dicionário completo ("0;T", "1;q", elasticidade, attach_analytical!, solve) é da aula Laplace 2D.

1.1 Dois papéis do Gmsh no curso

AulaUso do Gmsh / BEM_gmsh
Indo para 2Dmalha, 𝑁𝑘, 𝐽, 𝐧, perímetro/área/centróide
Laplace 2DCDC nos grupos físicos, montagem 𝐻,𝐺, solve, erro

1.2 Lembrete de instalação

using DrWatson
@quickactivate :BEM
include(datadir("Laplace", "Laplace_dad.jl"))

GUI do sistema: gmsh.info.

1.3 Grupos físicos → CDC (adiantado)

A partir de Laplace 2D, os nomes das curvas físicas carregam tipo e valor:

NomeSignificado (Laplace)
"0;T"Dirichlet: potencial/temperatura 𝑇
"1;q"Neumann: fluxo 𝑞=−𝑘𝜕𝑇/𝜕𝑛

Exemplos: "0;100", "1;0" (isolado). Elasticidade usa tx;ux;ty;uy (ver Laplace / elasticidade).

Até lá, nos .geo de geometria pode usar só nomes descritivos ("contorno", "Domain"), como na aula anterior.

1.5 Boas práticas (repete o essencial)

  1. Contorno externo anti-horário; furos horários.
  2. Elementos descontínuos no campo (format2d) — cantos sem nó compartilhado de CDC.
  3. ordem da malha alinhada a tipo.
  4. Estudo de convergência: variar ndiv e medir erro (capítulo de erros + Laplace).
